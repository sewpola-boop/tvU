# 지방정부 tvU 데이터랩 — Railway

ChatGPT Sites의 최신 화면과 관리자 기능을 Node/Vite 서버로 옮긴 버전입니다. Docker가 화면과 서버 번들을 모두 빌드합니다.

- 관리자 URL: `/sysop` (`/admin`도 호환). 초기 아이디 `admin`, 초기 비밀번호 `1111`. 로그인 후 비밀번호 변경 메뉴를 사용합니다.
- 비밀번호는 서버 데이터 경로에 해시로 저장되며 비밀번호 변경 시 기존 세션은 만료됩니다. 데이터와 계정 유지를 위해 Railway 영구 볼륨을 `/data`에 연결합니다.
- Railway 생성 도메인은 자동 인식합니다. 자체 도메인은 `PUBLIC_ORIGIN=https://도메인`을 설정합니다.
- 메인은 공개 열람하며 관리자 편집은 `/sysop` 로그인으로 보호합니다. 기존 `ADMIN_PASSWORD` 환경변수는 더 이상 메인에 인증을 걸지 않습니다. 전체 사이트의 별도 접근 인증이 필요하면 `PREVIEW_PASSWORD`를 명시적으로 설정합니다.
- 구독 플랜, 질문 제목/정렬, 홈페이지, 표/수식, 단체장/정당, 지도 색상/효과를 편집할 수 있습니다. 초기 구독가격은 무료 0원, Plus 월 300,000원/연 3,000,000원, Pro 월 600,000원/연 7,000,000원입니다. 결제와 유료 권한 부여는 미연결입니다.
- 전국 단체장 자료는 수집/재직 확인 상태를 구분합니다. 지도는 2023년 원도형을 바탕으로 전남광주 통합과 인천 2군 9구를 표시한 시연 경계입니다. 최신 정밀 경계와 차이가 있을 수 있습니다.
- 서버의 기존 `draft.json`과 `published.json`은 유지하고 누락된 설정만 기본값으로 보완합니다. ChatGPT Sites에서 저장한 편집본은 관리자 설정 JSON 내보내기/불러오기로 이전합니다.

개발: `npm install`, `npm run build`, `PUBLIC_ORIGIN=http://127.0.0.1:3000 DATA_DIR=./data npm start`. 서버 데이터 경로는 GitHub에 올리지 않습니다.


## 데이터 채팅과 향후 OpenAI 연결
- `/api/chat`는 서버에서 공개·검색 연결 자료만 조회합니다. 대화 내용은 채팅창을 닫으면 삭제됩니다. 무료 질문 횟수는 서버에 누적 저장되며 창 닫기만으로 초기화되지 않습니다. 최신 24개 메시지/2만 글자 이내의 문맥만 API로 보냅니다.
- 기본 설정은 원수치 검색입니다. OpenAI 연결 시 Railway 서버 비밀 변수에 `OPENAI_API_KEY`, 사용 가능한 모델 ID인 `OPENAI_MODEL`, `OPENAI_CHAT_ENABLED=true`를 설정합니다. 프런트엔드/VITE 변수, 소스, 관리자 공개 설정에는 키를 넣지 마세요.
- AI 호출은 초기에는 관리자 세션에 한정합니다. 일반 방문자는 키 설정 후에도 자료 검색을 제공합니다. 회원·유료구독 AI 공개는 서버의 구독 권한 검증과 연동한 뒤 별도로 확장하세요.
- Responses API 서버 어댑터는 최근 대화 및 검색된 자료를 전달하고 `store:false`로 호출합니다. API 키 없이 모의 응답으로 검증했으며 실제 유료 API 호출은 수행하지 않았습니다.
- 공식 참고: https://developers.openai.com/api/docs/guides/conversation-state

## 중앙 채팅창·월간 랭킹
질문을 보내면 메인 화면 위의 세로형 모달이 열립니다. 배경 흐림, 키보드 Esc/닫기, 대화 스크롤을 지원하며 공개 자료에 연결된 단체장과 설정 차트를 답변에 함께 표시합니다.
월간 TOP 10은 활성 평가 지표별 순위와 종합순위를 10초 간격으로 순환합니다. 마우스·키보드 조작 중에는 순환을 정지합니다. 관리자 순위 편집에서 실제 해당 월 자료를 확인하고 비교 기준을 저장한 뒤 다음 월 자료를 입력하면 상승·하락을 계산합니다. 비교 기준이나 비교 지역이 바뀌면 변동을 표시하지 않습니다. 기준 미입력은 비교자료 없음이며 가상의 상승·하락을 넣지 않습니다.

## 운영 데이터 보존 원칙
- 기능 업데이트는 코드·화면·지도 경계만 배포하며 `/data`의 발행본·초안·사진·원자료·회원·계정 파일은 배포물에 포함하지 않습니다. 영구 볼륨과 `DATA_DIR=/data`를 유지합니다.
- 저장된 단체장의 이름·사진·정당·색상·경력·정책·공약·범죄이력 사실·출처를 수집 기본값으로 덮어쓰지 않습니다. 통합 지역의 내부 연결키·직책·지역명 별칭만 호환 처리하고 인천 신설 구의 누락 입력란만 추가합니다.
- 서버 시작 시 기존 `published.json`과 `draft.json` 원문을 `/data/history/deploy-<내용해시>-<파일명>`에 보관합니다. 같은 내용은 중복 백업하지 않습니다. 읽기나 재시작만으로 원본 파일을 바꾸지 않습니다.
- 운영 데이터의 일괄 교체·초기화·다른 사이트 편집본 가져오기는 기능 업데이트와 별개의 명시적 작업입니다.
